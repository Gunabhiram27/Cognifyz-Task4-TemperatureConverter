# Task 4 – Temperature Converter 🌡️

This console app converts temperatures between Celsius and Fahrenheit based on user input.

## 📌 Features
- Convert Celsius ⇄ Fahrenheit
- Repeats until user exits
- Clean input-output loop

## 🛠️ Technologies Used
- Java
- Maven
- IntelliJ IDEA

## 🚀 How to Run
1. Open the project in IntelliJ
2. Run `TemperatureConverter.java` from the `com.cognifyz` package
